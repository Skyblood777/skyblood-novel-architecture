# Skyblood: Das Erwachen des Morgensterns 🌌🤖

Welcome to the technical architecture behind **Skyblood**, a 335-page urban fantasy novel fully architected, engineered, and co-authored utilizing advanced Generative AI and Prompt Engineering frameworks.

## 🛠️ The Tech Approach
Writing a high-volume novel with LLMs isn't just about typing a creative prompt—it is about **Context Management, State Control, and Logical Architecture**. Without strict guardrails, LLMs suffer from context drift and hallucinations. This project serves as a proof-of-concept for managing large-scale, long-term AI text generation.

## 🚀 Key Engineering Highlights
* **Modular Prompting:** Developed a decoupled system of *System Prompts* (style/tone) and *Functional Prompts* (chapter plots) to maximize the LLM's attention span.
* **State & Consistency Management:** Utilized a centralized Markdown-based Lore Book to feed persistent state variables (character traits, magic rules) back into the context window.
* **Deterministic Output Alignment:** Refactored and "debugged" AI outputs to eliminate narrative contradictions and logical gaps across 24 chapters.

## 📁 Target Repository Overview
* `/core-architecture`: Contains the system rules of the universe and the character relational databases.
* `/prompt-engineering`: The actual prompt code, prompt libraries, and debugging documentation used during development.
* `/book-assets`: The compiled production-ready PDF and AI-generated cover.
